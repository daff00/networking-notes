- **Purpose:** This layer handles hop-to-hop delivery of data within a single LAN (Local Area Network).
- **Key Idea:** It uses **MAC (Media Access Control) addresses** to identify specific physical interfaces on a local network, and **switches** operate at this layer to pass messages locally.
- **What is a Hop?** A hop is one step along a path between two devices, from one router or host to the next. For example, if a message travels from PC1 to Router 1, then to Router 2, and finally to Server 1, that journey takes three hops. Switches simply extend the local network and do not count as hops.
- **Protocols:** Ethernet and Wi-Fi are the dominant protocols at this layer

Can also be called Data Link Layer
